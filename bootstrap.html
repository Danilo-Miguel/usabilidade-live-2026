1. Tipografia e cores

O que são class aqui? Cada palavra dentro de class="..." é o NOME de uma regra CSS que já existe dentro do arquivo bootstrap.min.css que carregamos no <head>. Um elemento pode ter várias classes ao mesmo tempo, separadas por espaço — cada uma aplica um pedaço do visual final.

2. Grid de 12 colunas

Toda linha (.row) tem 12 "fatias" para distribuir entre as colunas (.col-*). O número depois do hífen é quantas fatias aquela coluna ocupa. Redimensione a janela do navegador para ver o próximo exemplo mudar de 3 colunas para 1 coluna no celular.

3. Espaçamento: m-* e p-*

Padrão do nome: {m ou p}{lado}-{tamanho 0 a 5}. m=margin (fora do elemento), p=padding (dentro do elemento). Lado: t topo, b embaixo, s início/esquerda, e fim/direita, x horizontal, y vertical, ou nenhuma letra = todos os lados.
p-0 (padding zero)
p-2 (padding pequeno)
p-4 (padding grande)
mt-5 (margin-top grande, empurra este bloco pra baixo)

4. Componentes prontos

4.1 Botões

.btn é a classe BASE (formato/cursor/padding). Sozinha ela não tem cor a cor vem de uma segunda classe, tipo .btn-primary.

4.2 Card

.card = moldura com borda arredondada + sombra leve. .card-body = área de conteúdo com padding interno. .card-title/.card-text ajustam a tipografia para o contexto (espaçamento entre título e texto).

4.3 Alerts

role="alert" não é do Bootstrap é um atributo ARIA de acessibilidade que faz leitores de tela anunciarem a mensagem automaticamente. O Bootstrap recomenda usá-lo em conjunto com .alert.

4.5 Formulário

for="email" no <label> e id="email" no <input> são HTML PURO (não Bootstrap): eles precisam ser IGUAIS para que clicar no texto do rótulo foque o campo automaticamente importante para acessibilidade.

7. Componentes interativos (precisam do bootstrap.bundle.js)

7.1 Accordion

Cada item usa data-bs-toggle="collapse" apontando via data-bs-target para o id do conteúdo que deve abrir/fechar. O data-bs-parent garante que só um item fique aberto por vez.
